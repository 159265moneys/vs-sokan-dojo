# VS ソカン — 五目道場

スマホ向けの縦持ち五目並べ。固定アスペクト比を持たず、端末の画面いっぱいに表示する。盤面は利用できる高さと幅で縮尺を変え、セーフエリアにも追従する。素のHTML / CSS / JavaScript + Rapfi WebAssembly。外部ゲームエンジンやサーバー計算は不要。

[ゲームを開く](https://159265moneys.github.io/vs-sokan-dojo/)

## GitHub Pagesへの公開

`dist/` をGitHub Pagesへ配信する。定期実行は設定せず、公開ワークフローは手動実行する。

```sh
git push origin main
gh workflow run pages.yml --ref main
```

ワークフローはゲーム・Rapfi・教材の検証後に公開する。Web App Manifestの起動先とスコープは相対指定で、プロジェクトURL配下に対応している。

## 起動

```sh
cd sokan-dojo
npm run dev
```

http://127.0.0.1:4173 を開く。ES modules / Web Worker / WASMを使うため、HTMLの直接ダブルクリックでは動作しない。Node.js以外の依存インストールは不要。

## できること

- 15×15、黒先手、禁手なし、5連以上で勝ち。
- Rapfi NNUE対局。普通 300ms・strength 35 / 強い 1800ms・85 / 最強 8000ms・100。いずれも1スレッド。
- 勝ち切る7つの教材を一手ずつ再生。回転・反転8通りのパターン反復。
- 解説アシスト、四追いの検証、推奨点・読み筋。
- 一手ずつの棋譜検討、黒の全手解析、見落としと改善手、変化手順の盤上表示。
- 戦績、途中局面の復元、棋譜JSONの書き出し・読み込み。待ったやヒントはアシストとして記録。
- 6種類の効果音（初期ON、切替を保存）、キーボード操作、ホーム画面追加用Web App Manifest。

対局では交点を選択し、座標付きの「打つ」で確定する。誤タップによる即着手を防ぐ。学習・反復は下部タブ、教材選択はプルダウン。

## 完全解について

このルールの初期局面には黒の必勝戦略がある。しかしこのアプリは完全解データベースではない。全応手網羅・初手からの最短必勝・CPUの無敗・対人勝利を保証しない。レッスンは検証済みの局所教材、Rapfiは制限時間付き探索、四追い確定は局面限定の証明。詳しくは [RESEARCH.md](docs/RESEARCH.md)。

## 保存・配布

棋譜と戦績は同じブラウザー・同じオリジンのlocalStorage。端末間同期はしない。保存に失敗したときは通知し、棋譜を書き出せる。ローカル版と配布サイトの保存領域は別。学習済みの印は初回・ヒントなし正解で更新。

`dist/` が配布物。Rapfiのモデルを含むため約42MB。古いSIMD非対応ブラウザーではエンジンを起動できない。初回読み込みには通信が必要。PWAのオフライン動作やストア配信は未実装。予約実行・heartbeat・自動再開の仕組みは使っていない。

Rapfiのライセンス、著作者、固定したソーススナップショットは `dist/engine/`。NNUEデータを16MBずつ3分割して読み込み時に復元する。盤と石は専用SVG / CSS、操作アイコンはSVGスプライト、CPUは専用SVG。SEは独自に合成したWAVを使用。音素材や画像の外部ライブラリーは使用しない。

## 検証

```sh
npm test
node tests/engine-smoke.mjs
python3 tests/shortest.py
```

前者は勝敗ルール・教材・56変換・全防御応手の証明・棋譜検証。後者は配布するRapfi WASMそのものを起動し、即勝ち・防御・遠方の四・長連を検証する。[VALIDATION.md](docs/VALIDATION.md) に実画面の確認範囲を記載。
