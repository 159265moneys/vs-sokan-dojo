# VS 楚涵 — 五目並べ

[ゲームを開く](https://159265moneys.github.io/vs-sokan-dojo/)

スマホ向けの自由五目。15×15、黒先手、禁手なし、5個以上で勝ち。HTML / CSS / JavaScriptとRapfi WebAssemblyで動く。

iPhone 15相当の393×852を基準に盤本体を389×389（画面面積の45.2%）へ固定。説明の分量・誤答・CPUの思考で盤を縮めない。ヘッダー・盤・石の既存素材を保ち、学習体験を全面再構築した。

## 三つの場所

- **学ぶ**：9単元・22基礎課題＋36の独立確認盤。自分の勝ちの優先、形の成立条件、序盤の連携、早期防御、四の順序、相手の反撃、応手による方向転換、静かな準備、実戦局面。盤上の見本→自力の回答→相手の応手→継続判断で進む。診断→必要な補習→未見の別問題→空盤の課題対局へ進む。白の妨害後の方向転換、守備後の再展開、五連までを本人が打つ。実戦問題・復習はこの中に置く。
- **対局**：CPUとの一局に集中。普通300ms / strength35、強い1800ms / 85、最強8000ms / 100、1スレッド。交点を仮選択して「ここに置く」で確定。待った・ヒント・拡大が使える。教材のショートカットは置かない。
- **振り返り**：対局履歴と結果をまとめる。具体的な勝ち筋を説明できる場面を探し、最初に「ここへ打てば何を作れた／防げたか」を示し、実戦と改善手順を同じ盤で比較。活三・飛び三・四三・三三・四四・受け四・四追いなどを型名と発光で示し、同じ局面で試し直し、採用した手を引き継いでCPUと終局まで続けられる。全棋譜も一手ずつ再生できる。

普通は木盤、強いは高級木盤と黒曜石・真珠、最強は黒い盤と淡いマグマ格子・赤青の石。効果音6種、音の切替、キーボード、ホーム画面追加用アイコン・manifestを含む。

## 教材と採点

回転や平行移動で問題数を水増しせず、独自作成した比較局面と本アプリの実戦棋譜を使用。同じ形でも相手の一石・受け方・手順の順序で結論が変わる例を含む。勝ち問題は初手だけでなく、黒が最後の五連を作るまで回答する。

証明済みの勝ち、限定した防御目標、比較活動を区別する。作者の予定手以外も検査する。未確認の手を敗着とは呼ばない。四三・三三を無条件の勝ちにせず、逆四・即勝ち・外側の空点を検査する。導入を見たこと、補助付き完了、初見の自力完了は別に記録する。

レビューは評価値の低下を説明の代用品にしない。四追いと三をつなぐ攻撃を最大9半手・上限付きで検査し、具体的な反証と局所的な改善を表示する。探索不発は安全・互角の証明ではない。VCT全般や長い準備手まで解決する検討器ではない。すでに二つの勝ち口がある場面の最後の手を、回避可能な敗因として扱わない。

独立確認は異なる判断条件を必要とし、見本や同盤の再入力を初見へ戻さない。保持は24時間以上かつ別日の新構造問題で測る。確認に失敗すると、失敗した判断条件の補習へ戻る。確認盤が尽きた場合は、その技能を実際に遂行した別の無補助実戦を使う。

最強10局チャレンジは空盤・strength100/8000ms・無補助の専用試行。投了・中断を後の勝ちで穴埋めせず、同じ10試行の全勝を測る。

初期局面から黒の必勝戦略が存在する研究と、この有限教材・時間制限CPUは別である。完全解データベース、全応手の序盤暗記、最短必勝、対人無敗、最強CPUへの安定勝利を保証しない。

## 起動・検証

```sh
npm run dev
npm test
node tests/engine-smoke.mjs
python3 tests/shortest.py
```

プレビューは http://127.0.0.1:4173 。ES Modules / Worker / WASMを使うためHTMLの直接起動は非対応。Node.js以外の依存インストールは不要。

新しい教材・因果レビューの検証に加え、ゲーム規則・旧データ・既存エンジンの回帰検証を残す。`tests/shortest.py` は旧基礎例の局所最短手順を検査するもので、初手からの最短必勝を証明するものではない。

## 保存と配布

既存の棋譜と進行中対局は保持。新学習進捗は `sokan.learning-v2`、途中問題は `sokan.learning-attempt-v2` に分離し、旧進捗を新教材の習得へ移し替えない。v3の露出・確認台帳は `sokan.learning-path-v3`、課題対局は `sokan.journey-v3` / `sokan.practice-games-v3`。旧進捗は既知の履歴として保持し、新しい独立確認へ自動昇格しない。保存先は同じブラウザー・同じオリジンのlocalStorage。端末間同期はしない。棋譜JSONを書き出し・読み込みでき、学習記録もJSONで書き出せる。

`dist/`が配布物。モデルを含む初回通信は約42MB、SIMD対応ブラウザーが必要。オフライン起動は未実装。CPU読み込み中でも学習を開ける。予約実行・heartbeat・自動再開は使わない。

GitHub Pagesは手動公開する。

```sh
git push origin main
gh workflow run pages.yml --ref main
```

## 構成と根拠

- `app.js`：画面・対局・学習/レビューの統合、保存、入力。
- `board-view.js`：共通盤面・石・因果の強調。
- `curriculum.js` / `learning.js`：教材データ、別解と応手、進捗。
- `assessment-bank.js` / `learning-path.js`：未見確認、露出台帳、補習・保持・実戦の判定。
- `journey.js` / `training-sessions.js`：課題対局、本人の遂行、振り返り局面からの継続。
- `review-patterns.js`：型の成立条件、反撃、証明済みの勝ち筋候補。
- `causal-review.js` / `review-worker.js`：勝ち筋の証拠、改善、棋譜の走査。
- `game.js` / `engine-client.js` / `engine/`：ルール、四追いの証明、Rapfi。
