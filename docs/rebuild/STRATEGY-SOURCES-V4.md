## 1. 今回の結論

暗記させる中心は手順の丸暗記ではなく、**「自分の五 → 相手の五を止める → 勝ち切る手順 → 相手の次の狙い → 石を組む」**という判断順序である。最初の二つはルールから確定する。後半は候補を調べる順序であり、局面の最善手を自動で決める公式ではない。

型は「石が何個あるか」から教えず、「次にどこへ置くと何が完成するか」から教える。読者が示せるべきものは、四なら五の完成点、三なら達四への着手点とその両端、複合形なら相手の受けとその後の継続である。

四三・三三には、成功図と失敗図を同じ単元で置く。相手石を数個変えただけで勝敗が変わる自作四三例を、今回独立計算で確認した。説明を後から注意書きで修正するのではなく、最初から条件付きの読みとして導入する。

## 3. 盤を見る順番を、読者が実行できる言葉にする

### 3.1 最初に覚える五段階

| 順番 | 読者の頭の中の言葉 | 実際に探す点 | 結論の強さ |
|---|---|---|---|
| 1 | 「今、五にできる？」 | 自分の石を一つ置けば5以上になる全空点。飛び四の穴も含む | あればそこへ打って即勝ち |
| 2 | 「相手が次に五にする点は？」 | 相手の完成点を、重複を除いて数える | 1点ならそこが必須。2点以上なら、自分に即勝ちがない限り受け切れない |
| 3 | 「受けられても勝ち切れる？」 | 一手で異なる完成点を二つ作る手、四追い、確認できる複合攻撃 | 相手の全応手に勝ちが続くなら採用。型の名前だけでは確定しない |
| 4 | 「相手は次に何を作る？」 | 達四、四四、四三、三三、四追いの入口、二つの石群の接続点 | 直接の受け、先回り、攻防を兼ねる受け、より速い攻めを比較 |
| 5 | 「次の攻めをどこに用意する？」 | 二方向に働く点、伸びる空間、将来の完成点、相手の反撃を減らす点 | 準備手の比較。中央・形の名前だけで最善とは断定しない |

第2段階は「相手の四が見えたら何でも止める」ではない。第1段階で自分がその場で勝てれば、そちらが先である。また一手の四受けは一つの空点を埋める行為なので、二つの独立した完成点は同時に消せない。これは捕獲・移動のない本ルールから直接導ける。

第3段階は無制限に読み続ける指示ではない。まず即座に二つの勝ち点を作る手と、応手の少ない四追いを調べる。勝ち切れない／まだ読めない場合は第4段階へ進み、危険を放置して準備だけを選ばない。後から自分の三追いや準備手を比較するときも、相手の応手まで戻って読む。

### 3.2 視線の動かし方

相手の最後の石から、横・縦・右上がり・右下がりの4本をなぞる。線の途中の穴、石の両端、そのさらに一つ外の空点を確認する。続いて盤全体に視線を戻し、前から残っていた自分と相手の狙いを確認する。

「最後の石から4方向」は新しく変わった線を見つける方法であって、盤の残りを捨てる規則ではない。以前の三や、離れた四追いの材料は残っている。自分の着手を仮に置いた後も、相手の最後の応手を置いた後も、この順に見直す。

### 3.3 教材の図で見せるもの

一つの図にすべての矢印を重ねない。「現在の石 → 次の完成点 → 相手の受け → 残る完成点」を別フレームで見せる。自分の狙いと相手の狙いは色だけに頼らず、点の輪・数字・矢印の形でも区別する。着手順は小さな数字で示す。

全盤と局所の拡大を往復できる構成にする。拡大図の端を実際の盤端に見せない。図外の石を省く場合も、元の全盤と手番は保持し、「局所で成立する型」と「この局面で勝てること」を別に検証する。

## 4. 型は完成点と必要な空点で覚える

`X` は自分の石、`O` は相手の石、`.` は空点、`|` は本当の盤端。以下は線の構造を説明するための原図で、対局全体の勝ちを単独では主張しない。

### 4.1 四と達四

```text
O X X X X .       完成点は右の1点
X X . X X         完成点は中央の穴1点
. X X X X .       完成点は左右の2点
```

四とは、次の自分の一石で五が完成する形である。4石が連続している必要はない。達四は両端が空いた連続4であり、相手が片方を埋めてももう片方で五を完成できる。ただし、相手が先に五を完成できるなら、達四を作った側が先に負ける。

「線が二本ある」「5マスの区間を二つ見つけた」と「異なる完成点が二つある」は同じではない。完成点の座標を列挙して重複を消す。同じ点を二度数えてはならない（自作図D参照）。正式な四四の名称と、単に四の線を複数数えたことも区別する。

### 4.2 本当の三

```text
..XXX..    左右どちらの隣へ伸ばしても達四
O.XXX..    右隣へ伸ばすと .XXXX. が残る
.XX.X.     内部の穴を埋めると .XXXX.
O.XXX.O    どちらへ伸ばしても達四にならない
|XXX..     左側が盤端。右へ伸ばしても達四にならない
|.XXX..    右隣へ伸ばせば .XXXX.。盤端付近でも成立する
```

三を調べるときは、一つ石を加えてから、できた四の両端を指で示す。石が3個あるだけでは三とは呼ばない。本書で「三」というときは、達四へ進める三を指す。片方を閉じられた三石の形は、必要なところで「片側が閉じた三石」「眠三」と区別する。

外側の空点は飾りではない。`..XXX..` の外側の一つだけを相手が埋めても、反対へ伸びる達四が残る。一方、`O.XXX..` は伸びられる向きが一つなので、その伸びる点だけでなく、将来の達四の両端を先に塞ぐ受けも成立する。まず仮の四を描いて確かめる。

### 4.3 四四・四三・三三の順序

| 形 | 読者が必ず実演すること | ここで教える限界 |
|---|---|---|
| 四四／二つの完成点 | 異なる二点を示し、片方を受けた後にもう片方へ置く | 相手の即勝ちがないことを先に確認する |
| 四三 | 四の完成点に相手石を置き、残った三から達四へ進めるか調べる | その受けが相手の四・達四を作ることがある |
| 三三 | 一方を止めた後の他方の達四を示し、別の受け・逆四でも確認する | 二つの三の形だけで全盤の勝ちとは言えない |

四三を「四は必ず受けられるから、その間に三を伸ばせば終わり」と説明してはいけない。受け石も盤上で働く。三三も「相手は片方しか止められない」で説明を終えず、相手が先に五を作る／四でこちらに応手を要求する／より速い複合攻撃を作る場合を見せる。

## 5. 連続攻撃の解法を教える

### 5.1 四追い：次の石ではなく、最後の五まで読む

四を作るときは、相手の受け点にも相手石を置いて次の図に進む。自分の石だけ増やした想像図は使わない。「四 → 唯一の受け → 別方向の四 → 受け → 二つの完成点 → 五」を最初の解法例とする。

毎回確認するのは、相手がその場で五を作れないか、受けた石で相手の四ができないか、次に使う点が相手の受けで埋まっていないか、の三つである。相手の受けが四になっても、それを止める自分の次手が四になるなど、勝ちが続く場合はある。反撃を見つけただけで攻めを不成立扱いしない。

四を作った事実と、四追いで勝ち切れることは別である。四を一回作って止められ、攻めがなくなる手もある。四追いの読みが失敗したら「この読みでは勝ちを確認できない」とする。他の三追いや準備手までないことにはならない。

### 5.2 三を含む攻撃：一本の手順から応手の木へ

三に対しては受けが複数ある。解説では、代表の受け一つだけで勝利を宣言せず、反対側の受けと、内部・外側の受けを比較する。相手が別の四を作るなら、その四を受けた後に元の三へ戻れるかを調べる。

本書では「三追い」を三を中心とする連続攻撃の説明語、「VCT」を四も含む脅威を連続させる探索・勝ち手順の名称として区別する。「VCT＝三しか打たない」と定義しない。

最初の図では応手を2種類程度にまとめ、各枝の最後まで見せる。その後で、同じ手が複数の枝に効くことを示す。分類して省略した応手については、制作側が同じ理由で勝てると確認しておく。「相手もこちらの予定どおり打つ」ことを前提にしない。

### 5.3 静かな準備：まだ三を作らない手を説明する

準備手の説明には、少なくとも「次の具体的な狙い」と「相手に一手渡した後にもその狙いが残る理由」を置く。単に強い形、評価値が高い、AIが選ぶ、とは説明しない。

用語は機能から導入する。次に四三などを作る狙いがミセ、次に四追いを狙うのがフクミ、直接三を引かず形を整えるのが呼手、という順で扱う。詳細な用語の境界は資料間で揺れ得るため、各図では必ず実際の次手を示す。これらを同義語にしない。

準備図では、すぐ三を引く候補と一度組む候補を並べ、相手の受け石がどこに増えるかを比較する。四や三を作るほど良い、という誤解をここで解く。四の緊急度が三より高いことは、四を作る着手が常に三や準備手より良いことを意味しない。

## 6. 防御を六つの行動として教える

| 防御 | 図で比較すること | 省いてはいけない確認 |
|---|---|---|
| 即勝ちを止める | 相手の完成点を一つ埋める | 自分に即勝ちがあればそちらが先 |
| 三を直接止める | 伸びる点・穴・達四の将来の端を比較 | 形ごとに有効な受け点が異なる |
| 攻防を兼ねて受ける | 受けた一石で自分の三・四も作る | こちらの反撃より相手が速く勝てないか |
| 逆四で手順を変える | 三をすぐ止めず四を打ち、相手に受けさせる | その後に元の三が残ることがある。四を打っただけでは解決しない |
| 将来の急所を先に埋める | 接続点、四三の着手点、後で必要な空点を占める | その筋を消しても別筋が残っていないか |
| 攻めの材料を減らす | 二方向へ働く点、伸びる空間、将来のノリ手を比較 | 石の近さや個数だけで安全と判断しない |

最後の二つは、目の前の三の端を止める以外にも守りがあることを教える。ただし未検証の手を「これで助かる」としない。特定の攻めを消したことと、相手の全ての勝ちを消したことは違う。

攻撃の章で相手側に置いた受け石を、防御の章では自分の意思決定として読み直す。攻撃と防御を別々の型暗記にしない。

## 7. 序盤では何を作るのか

最初に作るのは五そのものではなく、**次の数手で三や四へ進める、互いに働く石と空点**である。自分の石が同じ方向に並ぶこと、二方向に使える交点があること、完成までの空間が残ることを、候補を比べる観点にする。

中央は出発点として説明しやすい。空盤のH8は長さ5の区間20本に含まれ、隅のA1は3本に含まれる（縦横斜めの全572区間を今回列挙して確認）。この違いは伸びる方向の余地を説明する幾何学的事実であり、20対3を勝率や評価値へ変換してはいけない。

2手目以降も中央だけを追うのではなく、次を比べる。

1. 自分の既存の石と同じ五の候補線を作れるか。
2. 一方向を止められても別方向へ働くか。
3. 将来の三・四に必要な空点が端や相手石で閉じていないか。
4. 相手の強い狙いや接続点を放置していないか。
5. すぐ三を引いた場合、相手の受け石が自分の将来の道を塞がないか。

「くら型」「四つ目」などは、上の働きを理解した後に名前を付ける。名前のある配置は候補を思い出す助けであり、必勝印ではない。石の距離が近ければ常に強い、斜めなら常に強い、相手から離れれば安全、といった新しい固定則も作らない。

序盤の比較図は、同じ自石配置に対し、相手石または盤端までの距離を一つ変える。最善を証明できない図では「どんな次の狙いが増えたか」を説明し、唯一正解の問題にはしない。

## 8. 読者に見せる章立て

各章は **考え方の文章 → 手順を追う図解 → 条件が変わる対照図 → 覚える一文 → 任意の練習** の順とする。正解を隠した盤を最初に置かず、読者がまず解法を見られるようにする。本文を読むだけで、練習に入る前の必要な説明を一通り得られる構成にする。

| 章 | 読者が理解すること | 必須の図解 | 覚える一文 |
|---|---|---|---|
| 1 五を作る点を見つける | 4方向、穴、5以上、両色の完成点 | 同じ四を回転した図、飛び四、自分も相手も四の図 | 「自分の五が先」 |
| 2 一手では止まらない形 | 完成点の数と線の本数の違い | 達四、片側を止めた後、共有完成点の図D | 「数えるのは勝つ点」 |
| 3 三を本当に三にする空間 | 達四にする手と、その両端 | 連続三・飛び三・端・外側が閉じた対照図 | 「一石足して、両端を見る」 |
| 4 二つの狙いを合わせる | 四四、四三、三三の働きと速度 | 成功四三A、失敗四三B、失敗三三C | 「形のあとに、相手の一手」 |
| 5 四をつないで勝ち切る | 四追いの探索と打つ順番 | 全手順、受け石で接続を失う順序違い | 「受け石も置いて読む」 |
| 6 三から攻めを続ける | 複数の受けと逆四を含む分岐 | 二つの受け、逆四で中断、元の三への復帰 | 「相手が変えたら、続きを変える」 |

### 検算の範囲と再現方法

今回は独立した短いPython計算で、15路の縦横斜めの長さ5の区間572本を列挙した。区間内の4石と空点を求める方式と、各空点へ一石加えて四方向の連続5を検出する方式で、A〜Dの途中局面を含む24件の色・局面の完成点集合が一致した。最終形に既存の五がないため、同じ石集合へ交互に置く履歴にも、それより前の五はない。勝敗の全ゲーム木やエンジン評価を調べたという意味ではない。

再現に必要な最小定義は次のとおり。自由五目では6個以上も連続5の区間を含むため、この判定で勝ちになる。

```python
N = 15
D = ((1, 0), (0, 1), (1, 1), (1, -1))
windows = []
for x in range(N):
    for y in range(N):
        for dx, dy in D:
            w = {(x+i*dx, y+i*dy) for i in range(5)}
            if all(0 <= a < N and 0 <= b < N for a, b in w):
                windows.append(w)

def point(s):
    return ord(s[0]) - ord('A'), int(s[1:]) - 1

def stones(s):
    return set(map(point, s.split()))

def winning_points(own, other):
    # 終局していない局面を対象にする。
    return {
        next(iter(w - own))
        for w in windows
        if len(w & own) == 4 and not (w & other)
    }
```

## 10. 黒必勝の研究と、暗記でできること

説明する研究上の事実は「このルールの空盤開始には、相手の応手に合わせて勝ち続けられる黒の戦略が報告されている」である。根拠はS1の§2・§7。今回その証明データベースを取得して再検証したわけではない。
