# 教材充足度の独立監査 v4

監査日: 2026-11-12。既存教材の基点: `46eec82d09d5ea86d213e72033852f6fbb31430f`。対象は現行アプリから使われる `curriculum.js`、`assessment-bank.js`、`learning.js`、`learning-path.js`、`journey.js`、`causal-review.js`、`review-patterns.js`。内容監査後に判定の穴M1を再現し、担当範囲を明示的に拡張して `assessment-bank.js / learning-path.js` と対応テスト2ファイルを修正した。ブラウザー操作・新規の人間実験は行っていない。

## 結論

**既存教材は、有限の局面で脅威を見つけ、応手を読み、最後まで実行する戦術練習として相当の内容がある。しかし「何を見るかを先に理解してから自由五目を組み立てる攻略書」と「一般の序盤・中盤で自分で方針を選び直す練習」は未充足である。** 問題が存在すること、採点が正しいこと、内容が広いこと、人間が習得できることを別々に判定する。

特に不足するのは、毎手使う判断順序、形の名前と働きをつなぐ定義、勝ちから逆算する構築、相手が予定と違う手を打った時の再評価である。これらを文章と図解でつなぐ攻略書には明確な役割がある。ただし、記事を追加しても未見の否定例、相手の反撃の検出、静かな中盤の候補比較、対戦相手の多様な応手の経験は増えない。

また、**二方向防御を一度も実行せず「四になる前に」を初回確認できる既存経路を実APIで再現し、二方向防御の新盤への置換と旧台帳の限定的な補正を行った**。これは記事不足ではなく、下位技能と確認familyの対応の問題であり、攻略書とは別の修正である。他の確認・練習の不足は残る。

先手の理論上の可能性と、読者がアプリ内で勝ち筋を発見・維持できることは同じではない。本アプリは全局面・全応手の先手戦略を提供せず、先手であっても最強CPUの完封を保証できない。既存の初見確認、別日保持、実戦転用、10局試験は測定する仕組みであり、人間に対する効果・最短学習期間・安定勝率の実証結果ではない。

## 横断的に不足する理解

### K1 — 毎手の「見る順番」が独立した読み物になっていない〔優先1〕

各単元のヒントとjourneyの現在局面の案内には、即勝ち、白の即勝ち、白の次の二重攻撃、方向転換、連結がある。しかし学習者が手を置く前に全体を理解し、対局中に自力で思い出す共通の手順としてはまとまっていない。

攻略書で必要なのは、少なくとも次の循環を一枚の図と対照例で示すこと。

1. 自分の今の五連完成点を全盤から探す。
2. 相手の今の完成点と受け切れる数を調べる。
3. 自分と相手の次の脅威を比べる。形の強さだけで先着を決めず、相手の即勝ち・受け四・強制手を読み直す。
4. 四の候補を仮に置き、相手が受ける点まで入れ、次の方向が残るか読む。
5. 強制手がなければ、空きのある連結と二つの将来案を作る候補を比べる。
6. 実際の相手の一手で、増えた脅威・塞がれた線・残った線を更新し、最初へ戻る。

これは「この順番を読めば必ず勝つ」というアルゴリズムではない。読む対象を落とさない思考手順である。練習側でも型名と目標を伏せた混合局面に適用する経験が必要。

### K2 — 名前を知ることと、その形が働く条件の距離〔優先1〕

活三・飛び三・四・飛び四・両端四・三三・四三・四四・受け四・逆四・両フクミ・四追いは `review-patterns.js` に定義と局所表示がある。基礎にも複数の正例・反例がある。しかし「石が三つ／四つ並ぶ」から「次にどの空点で何が起こるか」へ移る共通の説明、名前同士の関係、強制力の差を先に通読できない。

攻略書は、名前の列挙で終えず、構成石・延長点・五連完成点・外側の空き・相手の反撃を別の記号で示す必要がある。四三や三三の絵に「必勝」を貼るだけでは既存基礎より後退する。同じ数の石があっても、端・穴・相手石・手番の一つの差で結果が変わる図を組にする。

### K3 — 勝ちの形から逆に配置を作る連続した説明〔優先1〕

既存の順序・分岐・準備は有効な局面から始まる。journeyには空盤から置く行為が追加されているため、「構築練習が全くない」という批判は不正確。ただし二方向を作る幾何学と、相手が止め切れない攻めへ育つ条件の間には説明の空白がある。

攻略書では、五連←二つの勝ち口←応手を絞る四←次に残す三／別方向←その石を用意する二石と空間、という逆算を、一局の中で示す。途中で白が別の場所を閉じた比較図も必要。一本の模範棋譜を覚えることと、他の応手でも同じ原理を使うことを分ける。

### K4 — 序盤・静かな中盤で候補を比較する軸〔優先2〕

既存の序盤比較は連結と余地を扱い、未知の手を負けと断定しない点が適切。一方、複数の合法な静かな候補に対し、どちらが何を準備し、相手のどの返しで方針が変わるかを比較する材料は少ない。静かな準備4確認は全て証明済み勝ちへつながる特別な配置であり、一般の中盤評価の代用にはならない。

攻略書は空間、連結、共有点、相手の予定点、残る二つの案を観察軸として示せる。ただしこれだけで唯一最善手を決定したり、全白初手に対する先手必勝手順を供給したりはしない。実際に候補を挙げ、応手を比較して方針を更新する練習は別に必要。

### K5 — 守る場所と、守った後の働き〔優先2〕

受けは「三の端へ置く」だけではなく、共有点、穴、外側、相手の予定点、こちらの四による反撃を比較する必要がある。既存の先回り防御は複数正答を受理し、reviewも妨害の意味を分け、journeyは受け石から後で三・四を作る。ここは実装が全くない不足ではない。

不足は、それらを事前に説明する一貫した章と、受けた後に自分の即勝ちがない局面で継続する練習の厚みである。「受けが正しい」で問題を終える局所目標と、その後も戦える配置を選ぶ行為は別。

旧台帳は当該IDだけを限定補正する。旧attemptの元family・日時・成績・既知盤のfingerprintを保持し、`assessmentExclusion:'retired-defense-race'`を追加して独立確認・保持・復習後の再確認の証拠から除外する。他単元へは昇格しない。旧raceの失敗履歴も残すが、誤ってdefense補習を要求する根拠にはしない。古いバンクを渡す呼出しでもraceを新規確認として選ばない。

既存の正当なgap＋cross成功は初回確認として維持する。旧raceだけが後日の保持を供給する状態は保持確認にならない。旧race盤は遭遇済みのままなので、別IDを付けて再登録しても未見成功にならない。新しいcross-straight盤を過去に見た扱いにはしない。schema・他単元・実戦履歴を一括リセットしない。

盤の追加をしない代案は、raceをdefenseの確認対象から除外して残る3盤を用いること。しかしcross側が1盤になり、保持・補習後の未見再確認がより早く枯渇する。family移動だけの見かけの最小変更より、上記1盤置換の方が教材目標を維持する。

## 相対的に厚い箇所・重複・名前だけの充足

- **厚い箇所:** 四の応手を置いて次の方向へ進むVCF、二つの完成点、有限の準備手、証明された別解の受理、未判定を誤答にしない境界。ここを削って記事の量に置き換える必要はない。
- **有益な反復:** `prevent-junction / prevent-changed-arm`の一石差、`quiet-two-plans / quiet-shape`の行為と認識は同familyだが役割が異なる。重複familyとして正直に数えれば、削除すべき冗長ではない。
- **相対的な偏り:** 修正後も36確認のうち26課題は五連完了で、勝てる局面の実行が多い。一方、誤った攻めを見送る、まだ勝ち筋がないと認める、守備の候補を比較して再構築する確認は少ない。「各単元4問」を満たす均等配分は、各下位技能の網羅と同義ではない。
- **名前が広い箇所:** 「序盤」は連結比較と早期脅威、「静かな準備」は証明済み強制勝ちの入口、「実戦で見つける」は勝てる戦術の全盤探索、「相手の反撃」の確認は主に自分の反撃。「内容がない」のではなく、名称から想像する範囲より実際の測定が狭い。
- **図を増やす時の注意:** 同じ盤へ矢印や説明を足しても練習条件は増えない。既存の見本と確認盤は露出台帳で分かれているので、攻略書へ未見確認盤の解答図を転載すると確認バンクを自分で消費する。攻略書は既存基礎例か独立の新作例を用い、見せた盤の扱いを既存露出設計と整合させる。
- **出題の合図:** priorityの確認文は「黒の一手を選ぶ」に中立化されている。一方「四を続けて」「一手で勝ち口を二つ」「白の次を消す」などの目標は単元確認には妥当でも、何をするか自分で選ぶ実戦的診断とは別。混合確認では行為名を伏せる必要がある。

## 次に増やす練習の優先順

1. **defenseの誤対応の修正は実施済み。** 新盤の全合法手、反証、2family集計、旧race成功の除外、既存の正当な証拠の維持を回帰検査する。教材数を増やす前に意味を修正した。
2. **conditionsに正例／否定例を1組。** 同じ三から、外側が一石で閉じる場合・盤端にかかる場合を作る。「形の名前」ではなく、次に両端四へ進めるかとその理由を選ばせる。新しい初形として保持用の別構造も確保する。
3. **counterに相手の反撃あり／なしを1組。** 同じ黒の四三候補の白の受け点で、白の四が生まれる側と生まれない側を比較し、本人が白の返しを予測して黒の続きまで打つ。自分の受け四を作る既存2familyは別の成果として残す。
4. **型名を伏せた混合確認。** 今勝つ、受ける、四で続ける、二重攻撃を防ぐ、静かに組むの混合。毎回必ず勝ち筋がある分布にしない。静かな候補は事実比較・複数許容を使い、軽い探索で全局正誤を装わない。
5. **勝ち筋成立前の序盤・中盤の対照。** 同じ連結案に対する近接／遠い白、共有点の先取り、片方しか残らない図、両方が足りない図を用意し、候補生成と計画修正を練習する。模範手順との一致だけで採点しない。
6. **人間の小規模試用。** 読む前後の理由説明、未見混合問題、別日の保持、空盤対局の判断を別々に記録し、どの図・章・練習から誤概念が減るかを見る。児童生徒に対する効果や最強CPUの安定勝率は、その実測後に評価する。

### K1〜K5の更新
