# 学習画面の答え・ヒント表示契約（2026-11-13）

ユーザーの追加指定: 学習段階を問題として成立させ、本人がボタンを押す・回答する・次へ進むまで答えやヒントを先に出さない。

## 出題と解説を分ける

- 単元のカードは問題を開始する。自動で見本を見せない。攻略書と「見本を見る」は、本人が明示して開く説明として残す。
- 初期盤に表示できるのは設問で指定された候補・支持する黒石などのgivensのみ。正解点・正解方向・hint text・結果・正解フラグを初期UIへ出さない。
- 予測問題の正答後、本人の盤入力がまだ残る場合は解説を自動再生しない。指定の相手手を反映した盤と、次の課題条件だけを表示する。
- 誤答後、または問題全体への回答完了後には答え合わせを表示できる。理由・反証・改善手の具体性は削らない。
- 続き入力前に「予測した手順を見る」等で解説を要求した場合は表示し、補助として記録する。無補助の確認にはしない。
- 保存された解答済み・答え合わせ状態へ再読み込みした場合は一覧から入り、「前の答え合わせ」を押した時に開く。

## 表示状態と利用履歴

現在表示しているhint levelは、初期化・次の決定・retry・restore・画面再入場で0へ戻す。一方でuses/maxLevel/byDecision/指導閲覧/誤答/再試行/既知盤は維持する。表示を閉じることを、過去の補助や誤答の取消にしない。

補助や誤答を含んだ確認問題は「復習問題」と表示し、見た目でヒントが閉じても無補助初見へ戻ったとは誤認させない。

## 課題対局

盤に触れただけで推奨手・候補評価・次の正解方向を出す動作を停止。初期・次の自分の手番は課題の目標だけを表示し、ヒントボタンを押した現在の一手だけ助言・発光・選択候補の説明を出す。着手、再試行、別画面、再読み込みで閉じる。

本人が実際に置いた手への事後フィードバックと終局結果は表示できる。無補助の「一局を自分で」はヒントを備えない。解説の内部データを保持することと、UI/ARIAへ先出しすることは別に検査する。
