## 保存・評価の境界

記事スクロールと目次の開閉はstrategy-scroll-v1に保存。文章DOMは一度だけ構築し、CPUの描画更新やタブ往復で読書位置を消さない。見るための図と対局盤を別DOM/別CSSにする。

攻略書を対局/確認中に読む操作は補助として記録する。実際に表示された図はIntersectionObserverで基礎・v3台帳の両方に露出を記録し、読むだけで達成にはしない。完全棋譜を開いた場合は途中局面を含む36prefixを既知にする。過去に完了した独立成功は後の閲覧で書き換えない。現行36確認盤と記事43図/棋譜36prefixのD4・平行移動同一局面は0。
