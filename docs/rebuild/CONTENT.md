# 学習教材バンクと検証

2026-11-11。実装: dist/curriculum.js / dist/learning.js。9単元・21課題・19概念系列。目安の20〜30課題には入るが、独立概念を21と水増ししない。一石差の先回り防御と、静かな準備の認識/実行は同じfamilyとして記録する。

## 収録内容

|単元|課題ID|形式・判断|
|---|---|---|

各単元の見本は初期盤と説明から始まり、次の手で何が変わるかを1〜2文と盤上マークで示す。例「白はJ8を塞いで黒の五連を防いだ。縦の黒石のつながりは残っている」。解答点を先に出すだけのヒントにせず、見る範囲→関係する線→候補点と、戦術上の観点を返す。

## データの由来

- shared-point-order / counter-four-claim / prevent-junction / two-direction-fork: pedagogy-research.mdの自作A〜D。
- turning-attack / quiet-two-plans / defend-and-attack: gomoku-knowledge-research.mdの独立検証された自作3例。H8だけを唯一解にしない。
- 実戦3題: dist/expert-courses.json 内のmax-natural / max-white-h7 / max-white-h6の着手履歴。元履歴をsourceMovesとして教材内にも保持する。
- 条件比較・序盤比較・三三への受け四などの補助課題は今回の新規構成。外部書籍の図・解答文はコピーしていない。

## 採点の境界

五連以上、二つの勝ち口、強制応手を伴うVCFは、572個の5セル窓から判定する。VCFは毎手の相手の即勝ちを確認する。探索は最大9半手・1,600ノードを通常上限とし、不発/打切りを負けにしない。

初手が四を作らない三三・静かな準備は、全応手を検証した初手を収録し、選ばれた白応手後の継続を再検査する。未登録の静かな手まで、軽い実行時探索だけで全応手保証することはしない。相手の表示応手には再現可能な複数枝がある。

四三の勝ちを誤って主張したchoiceはgoal-missであり、学習者がその場で対局に負けたという表示ではない。盤上の実際の手が強制負けの場合だけproven-lossを返す。既知の悪い順序では、最終勝敗を断定せずobservation（correct:null）で「つなぎ目を取られる」と具体的な現象を示す。未登録かつ検証不能な候補はunknownとし、いずれも誤答数へは加えない。

prevent-forkのsolvedは「次の二重攻撃を防いだ」で、黒の勝ちではない。序盤比較もcomparisonの完了で、唯一最善・必勝の認定ではない。勝ち問題は白の応手の後、最後の黒の五連まで入力する。

## 状態と進捗

- 見本のFrame再生と、自力Attemptを分離。新しいAttemptの初期highlightsは空。
- 間違えた一石と、仮想反証の手順を分離。反証再生はhistoryへ追加しない。
- retryは同じ判断点へ戻すが、ヒント・誤答・未判定・再試行数を残す。
- choice完了時は、Viewが結果Frameの盤・最終点・マークをまとめて返す。Stateの初期盤履歴は書き換えない。
- 初見は開始時に記録。補助つき、再試行、自力、未判定を別軸で保持。同じattemptIdを再保存しても二重加算しない。
- 正解途中の案内はmarkLearningGuidanceで別記録。ヒント回数0でも、次の答えを含む案内を見た完了は補助つきであり、初見自力に加えない。実戦/復習の途中ではcontrollerが答えを含む説明・マークを表示しない。
- 旧教材の達成を自動移植しない。スケジュール・通知・heartbeatなし。

## 検証

再現コマンド: node --test tests/learning.test.mjs

テストは初期合法性、全見本/選択肢Frameの非空説明と座標整合、全21課題と5通りの応手、登録別解、最後までの継続、白に先に勝たれる選択、観察と未知の区別、入力不変、JSON復元、結果表示の盤/マーク整合、進捗の重複防止を含む。

独立照合には既存game.jsの方向走査を使い、新しい窓走査と異なる勝敗判定で確認した。静かな準備のH8/F8後は白全416応手、三三は全216応手、先回り防御2題は黒の全合法初手を検査する。四三への反撃は、白J8後の黒の全応手と、白H6後の黒の全応手を列挙して強制負けを確認する。

独立監査で序盤継続の固定正解一覧に漏れが見つかったため、版2026-11-11.2では形からの判定に置き換えた。G9→白G10後の三はE11/F10/I7/J6、G9→白I7後はG6/G7/G10/G11を受理する。F8→白I8後の四はD8/E8、白E8後はI8/J8を受理する。4分岐の全空点を列挙し、正解・未達・復元を検証する。自動案内を見た試行の補助記録・冪等性・復元・再試行も回帰テストへ追加した。現在16テストが通過する。

ローカルNodeで全play課題の合法初手2,713手を計測した際、合計約1.46秒、最も遅い一手は約27msだった。これは開発機の一測定で、スマートフォンの実測保証ではない。現在の収録範囲では同期処理を維持する。今後、静かな手の実行時全応手探索を追加する場合は事前生成またはworker化を先に検討する。

教材の棋理・データの正しさを検査したもので、長期棋力向上や最強CPUへの安定勝利を実証してはいない。全局面の最善手や全白初手を網羅した教材でもない。
