# 必勝と、覚える単位

調査日: 2026-11-10

## 今回の最優先事項

1. ルールと「必勝」の意味を固定し、証明と推奨を混同しない。
2. 実際に強いCPUと対局できること。
3. 自分の一手を振り返り、見落としと改善候補を具体的に示すこと。
4. 局所形の条件を含めて反復し、別の場所・向きでも認識できること。
5. スマホの操作、戦績、効果音・石・紋章の演出。

## 固定したルール

15×15の交点。黒から交互に1石。縦横斜めの5連以上で勝ち。長連、三三、四四は双方とも合法。交換ルール・初手制限なし。盤が埋まれば引き分け。

## 調査の結論

Allis、van den Herik、Huntjensの原論文は、自由五目と長連を勝ちとしない標準五目の初期局面について、黒の勝利戦略を示している。Victoriaは脅威空間探索と証明数探索を用いた。これは、任意の途中局面の最適手と最短距離が全部得られる「強解」ではない。

原典: https://cdn.aaai.org/Symposia/Fall/1993/FS-93-02/FS93-02-001.pdf
著者の学位論文章: https://renju.se/rif/proof/chap5.pdf

相手が完全最適でも、黒が証明された戦略を守れるなら負けない。一方、本アプリの推奨を真似する・教材を覚えるだけでは、その証明木を再現したことにはならない。実戦では黒でも負け得る。

## 「頻出パターンで圧縮できるのでは」という仮説

有効な学習設計として採用した。同一局所形の平行移動、回転、反転は共通に扱える。ただし盤の端までの空きと、周囲の石も必要条件になる。現在の実装で自動生成するのは8方向の回転・反転。平行移動やノイズ石の自動生成は未実装。

覚える単位は **局所形＋手番＋即勝ちの有無＋周囲の空き**。

- 四の両端が空くと、相手が先に五連を作れない限り、両方を一度に止められない。
- 四四は禁手なしなら使える。
- 四を続けると、相手の応手を強制できる。
- 離れた相手の四があるなら、こちらの四四より相手の五連が早い場合がある。
- 石は後で別方向の連結に使われるため、「死んだ領域」と独立に見なすには根拠が必要。

形は繰り返すが盤面そのものは石の増加によって変わる。完全最適な黒の勝ちは相手のミスを前提としない。「局所形の再利用」と「ミス待ちだけ」は同義ではない。

## 1手ずつの例

アプリ「型を学ぶ」の「四追いの連鎖」は、以下の局所教材を図で再生する。

開始: 黒 H6 H7 H9 G8 I8 / 白 H5 A1 C1 E1 A3 / 黒番。

1. 黒H8。縦の四。白がH10以外なら次にH10で黒勝ち。
2. 白H10。唯一の即負け回避。
3. 黒F8。横の四の両端E8とJ8が空く。
4. 白J8。E8を守る応手でも逆側が残る。
5. 黒E8。五連。

この開始局面では1手勝ちはなく、3手以内での強制勝利もないことを独立した全合法応手検査で確かめる。上の5手以内の勝ちが成立するため、この教材の最短最悪応手距離は5手。初期局面からの最短必勝手順を示したものではない。

## 最短勝利の扱い

白も勝敗について最適なら、黒勝ちの局面では複数の白の手が同じ「負け」という値を持つ。手数を定義するには、黒が勝利を最短化し、白が敗北を最長化する、という二次基準を加える。

初期局面からこの距離を確定するには、全応手を覆う証明と、それより短い強制勝利がない証明の両方が必要。今回その完全データは取得していない。Rapfi同士の一局や自己対戦サンプルを、その証明の代わりにはしない。

内蔵の四追い探索は、最大9半手・200探索節点・3.5秒以内に制限した十分条件の検査。自分の五連を優先し、相手の即勝ちを除外し、四に対する強制防御を辿る。二つの勝ち口があるときは、他の防御も即勝ちを防げないことを利用する。見つからなければ「未確定」であり、「必勝なし」「負け」とはしない。表示する上界はその局面からの手数であり、すべての攻め方を含む最短距離とは言わない。

## 敗因の表示

即勝ちの見逃し・唯一の四防御の見逃しは盤面から判定する。二つ以上の敵の即勝ちがすでにある局面は、その手を「守れば助かったミス」と誤診しない。一般局面は着手前後のRapfi評価を同じ側の視点に直して比較し、評価差250超を改善候補とする。評価の悪化だけでゲーム理論上の敗着とは断定しない。評価値は勝率ではない。

## もし「必勝なし」が判明したら

今回の確定ルールについては既存の黒必勝結果があるため、その条件には至っていない。別ルールを採用した場合は改めて確認する。

- 有限回のPythonシミュレーションで勝てないことは、必勝戦略が存在しない証明にならない。
- 未解決なら、完全な保証を外し、負けを避ける形・実戦勝率・ミスの削減を目標にする。
- 初期局面が引き分けと証明されたなら、最適な相手への勝利保証は不可能。引き分けを確保しながら相手の誤りを咎める練習へ切り替える。
- ルール変更やハンデで相手に勝つという変更は、ユーザーの意向を確認する。
