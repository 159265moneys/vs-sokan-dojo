# 最強CPUの実戦教材

この教材は空の15×15盤から、同梱のRapfiが実際に終局まで打った対局を再生する。黒勝ちを確認した対局だけを `dist/expert-courses.json` に収録する。局所問題から、序盤の配置、石の連携、相手への対応、四追い、終局までをつなぐための実例である。

## 生成条件

- 自由五目、黒先手、五連以上、双方の禁手なし。
- 黒の助言役と白の相手は別々のRapfiインスタンス。探索キャッシュを共有しない。
- 両者のstrengthは100。白は本アプリ最強と同じ1手8000ms。
- 黒も最初は8000ms。より長い探索を使った教材は各courseの`blackMs`にその値を残す。
- 1スレッド、hash 65536 KiB、最大深さ100、ノード上限なし、先読みなし。
- 実測時間`elapsedMs`は探索の早期終了や実行環境によって設定値と異なる。
- 初手など探索を省く場面では、Rapfiが評価値・深さ・読み筋を出さないことがある。存在しない情報は補わない。

実行例:

```sh
node scripts/generate-expert-courses.mjs --id max-natural --black-ms 8000 --white-ms 8000
node scripts/generate-expert-courses.mjs --id max-white-h7 --black-ms 8000 --white-ms 8000 --white-opening H7
```

2番目の例は白の最初の一手だけを指定する分岐教材。その指定手を「最強CPUが選んだ最適手」とは扱わない。`openingKind`、`forcedOpening`、該当着手の`forced`で区別する。以後の白は8000msで探索する。

## 記録と検証

生成中は毎手 `artifacts/expert-courses-progress.jsonl` と `artifacts/expert-course-<id>.json` を更新する。勝ち・負け・引き分けのいずれでも生成棋譜は残るが、黒勝ち以外は教材JSONへ公開しない。

各着手には、実際の座標、手番、設定時間、実測時間、Rapfiの生のINFO出力、着手前後の即勝ち点、近傍の自石、相手の石を挟まない同一直線上の自石、次に二つの勝ち口を作る点を記録する。説明はこれらの盤面上の事実から生成する。石がつながることや探索の推奨は、ゲーム理論上の最適性の証明ではない。

生のINFOは探索の最後の出力で、途中で打ち切られた探索のPVと最後に選ばれた着手が異なる場合がある。PVを実戦の手順と取り違えず、棋譜の再生には`moves[].i`を使う。ブラウザーのライブ助言でも同じ事実抽出器`dist/expert-guidance.js`の`annotateMove(boardBefore, i, side)`を使える。

`tests/expert-courses.test.mjs` は交互着手、空点への着手、終局後着手がないこと、最後が黒の五連であること、白の設定時間、固定初手の開示、各説明の盤面上の根拠を検査する。

## 学習の範囲と限界

1局を暗記するだけでは、相手が途中で別の手を選んだ場合に対応できない。教材再生で形ができる過程を学び、実戦アシストで応手ごとに読み直し、最後は助言・待ったなしの最強CPU対局で確認する。基本問題の完了を最強CPU攻略の達成とは扱わない。

収録した勝利例は有限の実戦サンプルであり、全白応手を覆う初期局面からの必勝戦略ではない。評価値や読み筋は探索記録であり、完全最適・最短勝利の証明でもない。端末性能、探索時間、キャッシュ状態でCPUの着手は変わる。人間の棋力向上、最強CPUへの継続的な勝利、楚涵への無敗は別途実戦で確かめる必要がある。

## 収録済みの実測

`max-natural` は黒8000ms・白8000ms、白の初手指定なし。43手目の黒M7で終局した。11手目I7で二つの勝ち口を狙い、白の四にH3・M3・L1で応じながら攻めを続け、41手目L6でM7とO6の二つの即勝ち点を作った。これはこの実戦記録の説明であり、11手目からの全応手を検証した証明木ではない。

`max-white-h7` は白の初手H7だけを指定し、以後は両者8000ms。35手目の黒E5で終局した。25手目D9で相手の四を止め、I3・G5・H5の四を続け、33手目F5で二つの勝ち口を作る。

`max-white-h6` は白の初手H6だけを指定し、以後は両者8000ms。27手目の黒B6で終局した。白の隣接初手とは違い、中央から二路離れた応手への例。25手目E9でB6とG11の二つの勝ち口を作る。

| 教材 | 白の初手 | 初手の選択 | 黒の勝ちまで |
| --- | --- | --- | --- |
| max-natural | G7 | 白Rapfiが探索 | 43手 |
| max-white-h7 | H7 | 教材用に指定 | 35手 |
| max-white-h6 | H6 | 教材用に指定 | 27手 |

計105着手、3局とも黒8000ms・白8000ms設定で黒勝ち。黒側だけの探索延長は使っていない。白初手の3形と、それぞれで選ばれた1本の実戦経路を収録したのであり、他の初手や途中の代替手を網羅したものではない。
